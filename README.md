## Data

Two directed graphs from the Stanford SNAP collection are downloaded automatically into `data/` on the first run:

| Dataset | Nodes | Edges | Content |
|---|---|---|---|
| [wiki-Vote](https://snap.stanford.edu/data/wiki-Vote.html) | 7,115 | 103,689 | Wikipedia administrator elections; edge i → j: user i voted on user j |
| [web-Stanford](https://snap.stanford.edu/data/web-Stanford.html) | 281,903 | 2,312,497 | Pages of stanford.edu (2002) and the hyperlinks between them |

If the automatic download fails with an SSL certificate error, download the files manually:
```bash
curl -o data/wiki-Vote.txt.gz https://snap.stanford.edu/data/wiki-Vote.txt.gz
curl -o data/web-Stanford.txt.gz https://snap.stanford.edu/data/web-Stanford.txt.gz
```

## Reproducibility notes

- **Software:** Python 3.10.7, NumPy 2.2.6, SciPy 1.15.3, NetworkX 3.4.2, Matplotlib 3.10.9, threadpoolctl 3.8.0.
- **Machine used for the reported timings:** macOS 13.7.8 (x86_64), 2.3 GHz dual-core Intel Core i5, 8 GB RAM.
- **Randomness:** one seed (`SEED = 42`). Every experiment creates its own generator from it, and ARPACK receives a fixed
  starting vector, so each cell gives the same result when run alone. The stochastic block model also depends on the
  NetworkX version.
- **Tolerances:** power iteration stops when ‖Gx − x‖₁ < 1e-10. `eigs` uses `tol=1e-10` for PageRank and `tol=1e-8`
  for the second eigenvalue. GMRES uses the sufficient 2-norm target 1e-10/√n.
- **Timings:** measured with one BLAS thread, best of 3 runs for short runs. Setup and solve are timed separately.
  Repeated runs on the same machine varied by about ±15%. The number of matrix-vector products is the
  machine-independent measure of work.
- **Runtime:** a full run takes several minutes. The slowest cells are the solver comparison (7.3) and the
  perturbation and warm-start experiments (7.6, 7.7), dominated by α = 0.99 on web-Stanford.
